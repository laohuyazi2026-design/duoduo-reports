# 多多研究報告倉庫

自動發布到：https://laohuyazi2026-design.github.io/duoduo-reports/

## 資料夾結構

- `reports/` — Markdown 研究報告（會自動轉成網頁）
- `slides/` — HTML 投影片

## 如何使用

1. 把 Markdown 檔案放到 `reports/` 資料夾
2. 把 HTML 檔案放到 `slides/` 資料夾
3. 執行 `git add . && git commit -m "新增報告" && git push`
4. 等待約 30 秒，檔案就會自動發布到網頁

## 範例 URL

- 報告：https://laohuyazi2026-design.github.io/duoduo-reports/reports/檔案名稱
- 投影片：https://laohuyazi2026-design.github.io/duoduo-reports/slides/檔案名稱
